# HEMS Agent 商业化能力图谱设计

## 概述

面向家庭 C 端用户的能源管理 AI Agent，服务于自研光储充网荷五合一一体机，通过 App 内 AI Chat 界面提供智能调度优化、自然语言交互和专业数据洞察。覆盖中国、欧洲、北美、澳洲等多个市场。

## 架构方向

**数据与规则引擎为核心 + 工具模块化架构**

- 核心投入在多市场适配的数据层和规则引擎上（电价引擎、政策规则、设备数据模型），作为所有上层能力的地基
- Agent 能力采用工具模块化架构，调度、预测、分析、控制等能力封装为独立 tool，Agent 负责意图理解和工具编排
- 关键控制场景有规则引擎兜底，不完全依赖 LLM 推理

## 已有能力与状态

|------|------|---------|
| 设备状态分析 | [已有] | get_energy_flow tool → 对应 1.1 |

| 用户记忆系统 | [已有] | 分层记忆架构 → 对应 5.1, 5.3 |

## 一、数据基础设施层 [P0]

### 1.1 一体机数据接口封装 [部分已有]

- **[已有]** 基础数据读取和指令下发能力（energy_flow / strategy tool）
- **[增强]** 统一数据模型：将五个子系统（光伏/储能/车充/电网/负荷）的状态字段和指令集形式化为 tool 层的数据契约，便于后续 tool 复用
- **[新增]** 指令安全边界：硬编码约束（SOC 下限保护、最大充放电功率、防逆流等），在 tool 层强制拦截，Agent 推理无法突破。采用纵深防御模型：tool 参数校验层 → MQTT 指令校验层 → 设备固件硬限制，三层均独立执行
- **[新增]** 固件版本适配：设备 OTA 升级后可能变更可用指令集和参数范围，数据契约需支持版本化，tool 层根据设备当前固件版本决定可用操作

### 1.2 多市场电价引擎 [新增]

分为两个独立子模块：

**1.2.1 规则型电价引擎**
- 电价结构建模：支持分时(TOU)、阶梯、容量等计费模型，按地区可配置
- 上网电价/补贴规则：并网售电价、自用补贴、度电补贴
- 电价日历：节假日、季节性调整、峰谷时段定义

**1.2.2 动态电价接入与预测**
- 实时电价 API 接入：对接欧洲 spot market（如 ENTSO-E）、澳洲 NEM 等动态电价数据源
- 短期电价预测：基于历史价格模式和外部信号的未来 24 小时电价预测（需 ML 模型或第三方服务）

### 1.3 数据质量与补全 [新增]

- 能量平衡校验：光伏发电 + 电网取电 ≈ 负荷 + 储能充电 + 车充，异常时标记
- 断连数据估算：设备离线期间的数据补全
- 异常跳变检测：功率/SOC 数据的突变识别

### 1.4 数据存储架构 [新增]

- 遥测数据分级存储：热数据（近 7 天，高分辨率）→ 温数据（近 90 天，降采样）→ 冷数据（历史归档，按小时聚合）
- 存储成本模型：按千户级别估算存储开销，指导采样频率和保留策略决策
- 历史数据查询接口：支持任意时间范围的聚合查询，为收益回溯、对比分析等场景提供数据

## 二、智能调度与优化引擎 [P0]

### 2.1 预测体系 [部分已有]

- **[已有]** 发电预测
- **[新增]** 负荷预测：学习家庭用电模式（工作日/周末、季节性），预测未来 24-48 小时用电曲线
- **[新增]** EV 充电需求预测：综合多种数据源——用户历史出行规律（作为基线）+ 用户主动告知（"明天 8 点出门"）+ 日历集成（如有授权）+ 车联网 API（如可对接）。纯历史模式预测准确度有限，需设计保底策略：无明确信息时默认按用户设定的"最晚出发时间"倒推充电计划
- **[新增]** 综合能量流预测：将发电预测 + 负荷预测 + 车充需求 + 电价日历合并，形成未来时段的"能量供需缺口图"

### 2.2 多目标调度策略 [部分已有]

基于预测结果和电价数据，自动生成最优充放电计划：

- **[已有]** ECO 模式 → 经济最优：峰时放电/售电、谷时充电、光伏自用最大化
- **[已有]** GREEN 模式 → 绿色优先：最大化光伏自用率，减少电网依赖
- **[已有]** UPS 模式 → 备电优先：保持储能 SOC 在安全水位以上，应对停电场景
- **[已有]** FAST 模式 → 车辆优先：确保 EV 在出发前充满到目标电量
- **[新增]** 智能组合模式：Agent 根据用户画像、当前场景和预测数据自动推荐策略组合，或在时段间动态切换模式

### 2.3 实时调整与事件响应 [新增]

- 天气突变响应：光伏出力骤降时重新调整储能放电计划
- 电价信号响应：动态电价市场中价格突变时的实时套利决策
- 用户行为偏离：负荷实际远超预测时的应急策略调整
- 电网事件：停电/限电信号触发备电模式切换
- 极端天气预案：台风/暴风雪等极端天气预警时，提前最大化储能 SOC，准备长时间离网运行

### 2.4 策略效果闭环 [部分已有]

- **[部分已有]** 能量统计基础能力（PV 发电量/电网取电/负荷用电），财务收益计算需电价引擎(1.2)支撑
- **[增强]** 日/周/月回溯：实际执行结果与理论最优对比，量化 Agent 帮用户省了/赚了多少
- **[新增]** 策略参数调优：基于历史偏差数据，通过规则引擎调整调度参数（如峰谷切换时间偏移）。初期采用规则驱动的参数微调，后期可引入自动化 ML pipeline

## 三、安全与控制可靠性 [P0]

### 3.1 指令安全机制 [部分已有]

- **[已有但未完全集成]** SafetyGuard 类已实现模式校验逻辑，但当前未在主流程中调用，strict 模式下为硬编码拒绝而非真实校验，需重新集成
- **[增强]** 分级控制确认：常规操作静默执行；策略切换需告知用户；关键操作（强制放电到低 SOC、切换并离网模式）要求 App 内二次确认
- **[增强]** 安全执行强制化：当前 SafetyGuard 仅产生警告，需升级为硬阻断——tool 层校验不通过时直接拒绝执行，返回用户可读的拒绝理由
- **[新增]** 指令冲突仲裁：用户手动操作 > Agent 自动调度，检测到用户手动操作后 Agent 暂停自动调度一定时间窗口
- **[新增]** 指令执行确认与回滚：下发后校验设备是否真正执行，超时未响应则告警并回退
- **[新增]** 频率限制：防止 Agent 推理异常导致高频反复下发指令

### 3.2 LLM 幻觉防护 [新增]

- 数值事实锚定：所有数值必须来自 tool 返回的结构化数据，LLM 只负责组织语言
- 不可能操作拦截：指令参数超出设备物理能力范围时 tool 层直接拒绝
- 置信度标注：预测类结果需标注不确定性范围

### 3.3 错误分类与用户呈现 [新增]

商业化产品需要统一的错误处理策略，跨越安全层(3.1)、交互层(4.1)和多语言(4.4)：

- 结构化错误码：定义错误分类体系（设备通信错误/安全拦截/参数越界/服务不可用等），每个错误有唯一编码
- 用户友好消息：每个错误码对应多语言的用户可读消息，避免向用户暴露技术堆栈信息
- 严重级别标注：区分信息提示/警告/阻断/紧急，指导 App 端呈现方式（toast/弹窗/全屏告警）

### 3.4 权限体系 [新增]

- 角色区分：户主（完全控制）、家庭成员（查看+有限操作）、安装商/售后（诊断+维护模式）
- 操作审计日志：全部 Agent 指令可追溯——谁、什么时间、做了什么、基于什么原因
- 敏感操作时间窗：如深夜不执行可能产生噪音的操作

### 3.5 认证与会话管理 [新增]

- 用户身份认证：与 App 认证体系集成，Agent 会话绑定已认证用户身份
- 用户-设备映射：支持一用户多设备（多套房产）和一设备多用户（家庭成员共享），明确当前对话的设备上下文
- 会话生命周期：App 前台对话 → 后台保持连接（接收主动推送）→ 会话超时清理，确保 Agent 状态不泄漏

## 四、用户交互与 Agent 对话能力 [P0]

### 4.1 意图理解与多轮对话 [部分已有]

- **[已有]** 基础对话能力和 tool 调用
- **[增强]** 模糊意图解析：用户说"明天要出远门"→ 理解为"今晚把车充满 + 储能切备电模式"
- **[增强]** 多轮上下文保持：跨轮次的查询上下文连续性
- **[增强]** 操作意图确认：理解用户意图后先复述确认再执行

### 4.2 主动触达能力 [新增]

- 异常告警：设备故障、通信断连、SOC 异常下降等
- 收益播报：日/周/月定期推送收益摘要
- 策略建议：检测到用户行为模式变化时主动建议调整
- 政策/电价变动提醒：当地电价调整或补贴政策变化时通知并建议应对

### 4.3 可视化数据呈现 [新增]

Agent 后端返回结构化数据 + 图表类型标识，由 App 前端负责渲染：

- 内嵌图表：能量流向图、24 小时功率曲线、收益趋势图等
- 实时状态卡片：一体机当前状态的结构化展示（五子系统状态）
- 对比分析图：月度对比、策略切换前后对比等

### 4.4 多语言支持 [新增]

- 对话多语言：中/英/德/法/日等目标市场语言
- 专业术语本地化："上网电价" vs "feed-in tariff" vs "Einspeisevergütung"
- 单位和币种自适应：kWh/MWh、¥/€/$、摄氏/华氏

## 五、记忆与个性化系统 [P1]

已有分层记忆架构基础，以下为需增强的能力。

### 5.1 记忆分层增强 [增强]

在已有记忆系统基础上补充能源场景专用记忆：

- **[增强]** 事实记忆：补充设备安装参数、所在地区、电价套餐、家庭人数、有无 EV 等能源相关事实
- **[新增]** 行为记忆：从设备数据中学习的模式——用电习惯曲线、EV 出行规律、季节性偏好变化
- **[增强]** 偏好记忆：补充能源偏好提取——"更看重省钱"/"车不用充太满 80% 就行"
- **[已有]** 对话记忆：历史交互摘要

### 5.2 记忆驱动的个性化 [新增]

- 对话风格适配：识别"专业型"vs"小白型"用户，调整回答详细程度和术语使用
- 策略自动调参：学习到用户行为规律后自动调整调度计划
- 推送频率和时机：根据用户对通知的响应模式自动调整

### 5.3 记忆治理 [部分已有]

- **[已有]** 基础记忆管理能力
- **[增强]** 遗忘机制：过时的行为模式需要淡出（如用户换工作后通勤时间变化）
- **[新增]** 记忆冲突解决：口头偏好和实际行为数据矛盾时以最近的显式表达为准
- **[增强]** 隐私合规：用户可查看和删除 Agent 记忆，满足 GDPR "被遗忘权"

## 六、可观测性与运维保障 [P0 基础 / P1 高级]

### 6.1 Agent 行为监控 [P0 基础]

基础链路追踪是安全控制场景的调试前提，必须与控制能力同步上线：

- **[P0]** 指令执行链路追踪：用户意图 → Agent 推理 → tool 调用 → 指令下发 → 设备响应，全链路可追溯
- **[P1]** 对话质量追踪：意图识别准确率、tool 调用成功率、用户满意度
- **[P1]** 幻觉检测：自动比对 Agent 回复中的数值与实际数据源

### 6.2 调度策略监控 [P1]

- 策略偏差告警：实际收益与预期收益偏差超阈值时告警
- A/B 测试框架：新策略/新模型灰度对比效果
- 模型漂移检测：预测准确度定期评估，衰减时触发模型更新

### 6.3 系统可靠性 [P0]

- **[P0]** 降级策略：LLM 不可用时退回规则引擎执行基础调度，设备不停摆
- **[P0]** 通信断连处理：设备离线时暂停调度、缓存待下发队列、恢复后补发
- **[P0]** 多租户资源隔离：单个用户的异常请求不影响其他用户

### 6.4 离线与边缘场景 [P0 设计 / P1 实现]

作为全球部署的硬件产品，必须考虑网络不可用场景：

- **[P0]** 离线行为定义：用户网络断开时，设备按最后一次有效调度计划继续运行；App 显示离线状态和最后同步时间
- **[P0]** 恢复同步机制：网络恢复后，设备上报离线期间的数据，Agent 重新评估当前策略
- **[P1]** 边缘智能评估：评估是否需要在设备端运行轻量级调度规则，以应对长时间离线场景

## 七、商业化支撑能力 [P0 架构 / P1 功能]

### 7.1 多租户与计费 [P0 隔离 / P1 计费]

- **[P0]** 租户隔离：每个用户的数据、记忆、调度策略严格隔离，架构层面保证
- **[P1]** 订阅/增值分层：基础版（状态查看+基础问答）→ 高级版（智能调度+收益优化）→ 旗舰版（主动管家+VPP 参与）
- **[P1]** 用量计量：对话次数、调度调用量、数据存储量等维度统计

### 7.2 白标/OEM 能力 [P1]

- 品牌定制：Agent 名称、头像、对话风格可按合作方配置
- 功能裁剪：不同合作方可开启/关闭特定功能模块
- 数据归属：合作方可访问其旗下用户的聚合数据（脱敏后）

### 7.3 开放能力 [P1]

- Webhook/事件订阅：第三方系统可订阅设备事件和 Agent 决策结果
- VPP 就绪接口：预留虚拟电厂聚合商接入接口，Agent 可接受外部调度信号参与需求响应

### 7.4 合规与认证 [P0 架构]

合规要求影响数据存储架构和跨境传输设计，必须在架构阶段考虑：

- **[P0]** 数据合规架构：GDPR（欧洲）、个人信息保护法（中国）、CCPA（加州）对数据存储位置和跨境传输的要求
- **[P1]** 电力法规适配：各市场户用储能并网、售电的技术和法规要求
- **[P1]** AI 合规：欧盟 AI Act 等对 AI 决策系统的透明性和可解释性要求

## 八、竞争壁垒能力 [P2]

### 8.1 跨用户群体智能

在隐私合规前提下（需差分隐私或联邦学习等隐私工程基础设施）：

- 区域洞察：同区域用户群体数据聚合产生更准的发电预测和负荷基线
- 策略众筹：效果好的调度策略脱敏后推荐给同区域类似配置用户
- 电价验证：多用户实际电费账单交叉验证电价引擎准确性

### 8.2 设备全生命周期管理

- 健康度评估：基于电池循环次数、容量衰减曲线、逆变器效率趋势评估设备状态
- 预测性维护：在故障发生前主动提醒
- 残值评估与换新建议：结合设备衰减数据和新产品性能给出升级经济性分析

### 8.3 能源社交与对标

- 同类家庭对标：光伏自用率、电费节省等指标与同区域类似家庭对比
- 碳足迹可视化：绿色能源使用换算为碳减排量，生成可分享的"绿色成绩单"
- 社区排行/成就：游戏化元素增强用户粘性
